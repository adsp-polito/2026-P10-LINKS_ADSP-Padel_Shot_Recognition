# Padelyst: Padel Shot Recognition

Applied Data Science Project, Politecnico di Torino, 2026/27.

## The project

Given a video of a padel match, Padelyst finds **when** a shot is played and **which**
shot it is: forehand, backhand, smash, serve, dropshot, or other. It also says which player
played it. Besides the video, the only input is the ball position in each frame. Player
detection, pose estimation, shot detection and shot classification are built within the
project.

No baseline exists for this task: our results will be the first reference.

## Data

[PadelTracker100](https://doi.org/10.5281/zenodo.17020011) (CC BY 4.0): two excerpts from
the 2022 World Padel Tour finals, with ball positions, player positions, player poses and
shot labels.
